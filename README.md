
# 再切一刀就好

副標題：哪有賭徒天天輸

## 遊戲簡介

一款以原石抽取、玉石切割、收藏圖鑑為核心的瀏覽器遊戲。

## 第一階段

目前包含：

- 深色礦石工坊主畫面
- 金幣顯示
- 基礎導覽
- 本機存檔系統
- 金幣交易核心
- 手機版版面

## 開啟方式

建議使用 VS Code 搭配 Live Server。

1. 使用 VS Code 開啟專案資料夾。
2. 安裝 Live Server。
3. 對 index.html 按右鍵。
4. 選擇 Open with Live Server。

不要直接以 file:// 開啟，因為 JavaScript ES Modules 可能受到瀏覽器限制。
